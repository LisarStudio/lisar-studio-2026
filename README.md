# Lisar Studio 2026

Sitio web vanguardista de **Lisar Studio** — Estudio creativo especializado en:
- 🎨 Diseño & Modelado 3D  
- 🎬 Animación 3D & Reels Virales (@lisarstudiooficial)  
- 🏗️ Visualización Arquitectónica  
- 💻 Diseño Web & E-Commerce  

## 🌐 Ver Online

👉 **[https://LisarStudio.github.io/lisar-studio-2026/](https://LisarStudio.github.io/lisar-studio-2026/)**

## 🛠️ Tecnologías

- HTML5 + CSS3 Vanilla (glassmorphism, animaciones)
- Bootstrap 4.6
- Three.js (animación 3D fondo)
- `<model-viewer>` Google (visor 3D GLB interactivo)
- Bootstrap Icons

## 📁 Agregar Modelos 3D

Coloca tus archivos `.glb` en `assets/models/` y actualiza el array `portfolioData` en `assets/js/app.js`.
