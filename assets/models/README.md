# Modelos 3D GLB - Lisar Studio 2026

Coloca aquí los archivos `.glb` de tus proyectos 3D.

Cada archivo se mostrará automáticamente en el portafolio como un visor 3D interactivo con:
- Auto-rotación 360° suave
- Zoom con scroll / pellizco táctil
- Rotación manual con mouse / dedo

## Nomenclatura sugerida

```
proyecto-01-producto-lujo.glb
proyecto-02-calzado-deportivo.glb
proyecto-03-residencial-3d.glb
proyecto-04-bebida-fluidos.glb
proyecto-05-breakdown-cgi.glb
```

Luego actualiza el array `portfolioData` en `assets/js/app.js` con el campo `glbFile: 'assets/models/<nombre>.glb'`.
